On the site, open a board and select Name a suspect. The form lists the clues the cause has to survive, and an optional preview asks one model about each pair before you spend a bond. The real check is the validators.

<Steps>
<Step>

**Read the clues first.** A suspect is eliminated by one clue that makes it very unlikely, whatever else it explains. Say what the cause predicts: times, order and effects matter.

</Step>
<Step>

**Bring a bond.** At least 3 GEN. A suspect that survives gets it back; one that is eliminated gives it to the author of the chosen cause.

</Step>
<Step>

**Test it.** Anyone can ask the validators to label a pair. The matrix shows every pair, and the clue that eliminated a suspect is named on its card.

</Step>
</Steps>

import { createClient } from "genlayer-js";

if (!board.found) throw new Error(`no board ${id}`);
console.log(`${board.title} (${board.state}), ${board.pairs_tested} of ${board.pairs_total} pairs tested`);
for (const h of board.hypothesis_rows) {
  console.log(`H${h.idx} ${h.status.padEnd(10)} ${h.labels.map((l) => l || "-").join(" ")}  ${h.text}`);
}

```python title="web/examples/read_board.py"

import json
import sys

from genlayer_py import create_account, create_client
from genlayer_py.chains import studio_devnet

SUSPECT = "0xCAB6b984814166181b0eA7eeB451F635C945C7de"
studio_devnet.rpc_urls = {"default": {"http": ["https://studio-next.genlayer.com/api"]}}
# genlayer-py reads need an account; a throwaway one is enough, it signs nothing.
client = create_client(chain=studio_devnet, account=create_account())

board_id = sys.argv[1] if len(sys.argv) > 1 else "1"
board = json.loads(client.read_contract(address=SUSPECT, function_name="get_board", args=[board_id]))
if not board["found"]:
    raise SystemExit(f"no board {board_id}")
print(f"{board['title']} ({board['state']}), {board['pairs_tested']} of {board['pairs_total']} pairs tested")
for h in board["hypothesis_rows"]:
    print(f"H{h['idx']} {h['status']:<10} {' '.join(l or '-' for l in h['labels'])}  {h['text']}")
```
