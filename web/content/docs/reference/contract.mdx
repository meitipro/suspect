## open_board

Open a board for an incident. Sets the 7 day resolve window. Returns the board id.

## add_observation

```python
add_observation(board_id: int, text: str) -> int
```

Pin a clue for 1 GEN, which comes back to whoever pinned it when the board resolves. Anyone may pin; a clue cannot be edited or removed. Returns the observation id.

Refuses with:

- a board has at most … observations
- pinning an observation costs exactly … wei
- this board is resolved

## propose

```python
propose(board_id: int, text: str) -> int
```

Name a suspect with a bond of at least 3 GEN. At most 6 per board and 2 per author. Returns the hypothesis id.

Refuses with:

- a board has at most … hypotheses
- an author may propose at most … hypotheses on a board
- the bond is at least … GEN
- this board is closed to new hypotheses

## check

```python
check(hypothesis_id: int, observation_id: int) -> str
```

Anyone asks the validators to label one hypothesis and observation pair. Each pair is labelled once. Elimination and ranking follow in code. Never moves money out of the contract. Returns the label.

Refuses with:

- pair already tested
- the observation belongs to another board
- this board is resolved

## lock_board

```python
lock_board(board_id: int) -> int
```

Owner only. Closes the board to new hypotheses; clues may still be pinned and pairs checked.

Refuses with:

- only the owner of the board may lock it
- this board is not open

## resolve

```python
resolve(board_id: int, hypothesis_id: int) -> int
```

Name the cause. The owner may name any survivor at any time. After the 7 day window anyone may resolve in favour of a LEADING hypothesis, and when there is none anyone may resolve with 0 and every bond returns. The bonds of the eliminated hypotheses go to the author of the chosen cause; every other bond returns to its author, and each pinned clue's deposit to whoever pinned it. Balances only: withdraw() pays. Returns the amount credited to the chosen author.

Refuses with:

- a hypothesis is leading, name it
- after the window anyone may resolve in favour of a leading hypothesis only
- an eliminated hypothesis cannot be the cause
- name a cause: the window is still running
- only the owner may resolve before the window ends
- that hypothesis is on another board
- this board is already resolved

## withdraw
