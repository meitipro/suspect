Everything below is one file that runs: [`web/examples/quickstart.mjs`](https://github.com/meitipro/suspect/blob/main/web/examples/quickstart.mjs). Reads need no wallet; writes need an account with test GEN.

<Callout type="warn" title="Boards are public and permanent">Pin only what can be public. A clue cannot be edited or removed.</Callout>

## Set up

```js title="web/examples/quickstart.mjs"
import { createAccount, createClient } from "genlayer-js";
import { studioDevnet } from "genlayer-js/chains";
import { parseEther } from "viem";

const SUSPECT = "0xCAB6b984814166181b0eA7eeB451F635C945C7de";
const chain = { ...studioDevnet, id: 61997, rpcUrls: { default: { http: ["https://studio-next.genlayer.com/api"] } } };
const client = createClient({ chain, account: createAccount(process.env.PRIVATE_KEY) });

// Every write on Studio Next carries a fee deposit. check() runs the model, so it gets 3 rotations.
async function send(functionName, args, value = 0n, rotations = 1) {
  const estimate = await client.estimateTransactionFees({
    leaderTimeunitsAllocation: 600,
    validatorTimeunitsAllocation: 600,
    totalMessageFees: 0,
    rotations: [rotations],
  });
  const fees = { distribution: estimate.distribution, feeValue: estimate.feeValue };
  const hash = await client.writeContract({ address: SUSPECT, functionName, args, value, fees });
  return client.waitForTransactionReceipt({ hash, waitUntil: "decided", interval: 4000, retries: 120 });
}

const read = async (functionName, args) => JSON.parse(await client.readContract({ address: SUSPECT, functionName, args }));
```

Get test GEN from the faucet on the site, or from Studio Next's `sim_fundAccount` with the amount as a decimal string.

## 1. Open a board

A title of at most 80 characters. The board opens a 7 day window to resolve.

```js
await send("open_board", ["API outage, 14:02 to 15:10"]);
const newest = (await read("get_board", [""])).boards[0].id;
```

## 2. Pin a clue

A short fact, at most 200 characters, for exactly 1 GEN. The deposit comes back to you when the board resolves.

```js
await send("add_observation", [newest, "CPU stayed flat and traffic was normal."], parseEther("1"));
```

## 3. Name a suspect

A cause, at most 200 characters, with a bond of at least 3 GEN. At most 2 per author, 6 per board.

```js
await send("propose", [newest, "A traffic spike from one region."], parseEther("3"));
```

## 4. Test a pair

Anyone can call `check`. It takes about a minute, and `rotations: 3` leaves room for a second committee. A pair is labelled once.

```js
const board = await read("get_board", [String(newest)]);
const hypothesis = board.hypothesis_rows[0].id;
const observation = board.observation_rows[0].id;
await send("check", [hypothesis, observation], 0n, 3);
```

## 5. Read it back

The status, the labels against every clue and the clue that eliminated it come from the contract.

```js
const after = await read("get_hypothesis", [hypothesis]);
console.log(after.status, after.labels, after.killed_by_text);
```

## Resolve and withdraw

`resolve(board_id, hypothesis_id)` names the cause and settles the bonds, and `check` and `resolve` only credit balances. `withdraw()` pays the caller, to the caller, in its own transaction, and needs an External fee allocation at the root of the fee tree, which the site's `lib/genlayer-core.mjs` builds.

The contract is [`0xCAB6b984814166181b0eA7eeB451F635C945C7de`](https://explorer-studio-dev.genlayer.com/address/0xCAB6b984814166181b0eA7eeB451F635C945C7de).
